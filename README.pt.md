## Faça sua primeira imagem

1. **Escolha um efeito.** Abra um caso e verifique as entradas necessárias.
2. **Escolha sua ferramenta.** Copie o prompt em sua ferramenta de imagem ou abra a tarefa correspondente em dearsketch.
3. **Use seu próprio material.** Para resumos somente de texto, preencha os detalhes por escrito; para tarefas fotográficas, anexe as imagens necessárias. Edite o prompt e gere uma imagem.

[Todos public prompts](./docs/pt/prompts.md) · [Início rápido detalhado](./docs/pt/quickstart.md)
