## Perguntas antes de começar

**Um modelo reproduzirá exatamente o exemplo?**

Não. Estes são novos modelos públicos e não as instruções originais por trás dos exemplos existentes. A saída depende das imagens de origem, ferramentas e configurações. A habilidade pública prepara uma tarefa e alerta; não inclui modelo, acesso API ou créditos de geração gratuita.

**Todas as tarefas começam com uma foto?**

Não. Composições familiares, experimentações e layouts informativos podem precisar de várias fotos, um desenho original ou uma cópia exata. Alguns conceitos começam com texto. Cada caso lista suas entradas.

**Esses arquivos estão prontos para produção ou são resultados do cliente?**

As imagens são demonstrações do projeto. Verifique texto, transparência, dimensões e quaisquer requisitos de vetor ou impressão nos arquivos reais. Os termos de proveniência e redistribuição da imagem estão descritos na política de conteúdo.

[Política de imagem e conteúdo](./docs/pt/content-policy.md) · [Contribua com um caso](./CONTRIBUTING.pt.md) · [Atualizações](./CHANGELOG.pt.md)

As permissões de redistribuição de imagens ainda estão sendo revisadas. A visibilidade pública não concede licença irrestrita de imagem. Os recursos e preços do site seguem o site atual.
