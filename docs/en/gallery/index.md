## Display caliber

- Cases with reference images display all existing previews according to "Reference Materials/Result Examples".
- Cases without reference pictures use a single column to display the results, and indicate text input or input preview to be completed according to the actual material role.
- Reference materials and results are used to illustrate visual directions and are not guaranteed to reproduce the same effects.
