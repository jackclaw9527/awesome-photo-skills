<p><a href="https://dearsketch.com/hi/intent/i127-create-product-or-interface-icons.html?utm_source=github&amp;utm_medium=case&amp;utm_campaign=dearsketch-public-cases&amp;utm_content=i127_image"><img src="../../../assets/cases/i127-after.webp" alt="नई आइकन शैली — उदाहरण परिणाम" width="320"></a></p>

दृश्य दिशा को स्पष्ट करने के लिए संदर्भ सामग्री और परिणामों का उपयोग किया जाता है। सार्वजनिक टेम्प्लेट संलग्न छवियों के लिए मूल पीढ़ी निर्देश नहीं है, और समान परिणामों को पुन: प्रस्तुत करने की गारंटी नहीं है।

एक समय में केवल एक छवि उत्पन्न होती है, छवियों को अपलोड करने की कोई आवश्यकता नहीं है।

- **बदलें / परिवर्तन:** [OUTLINE OR FILLED] ज्यामिति, [STROKE WEIGHT], [CORNER STYLE] और [PALETTE] का उपयोग करें। एक सुसंगत ऑप्टिकल आकार के साथ आइकन को [BACKGROUND] पर केन्द्रित करें।

## Public prompt

**नया संकलित सार्वजनिक टेम्पलेट · ​​नवलिखित · पीढ़ी-परीक्षणित नहीं।** बस वर्गाकार ब्रैकेट पैरामीटर बदलें, संदर्भ चित्र अपलोड करने की कोई आवश्यकता नहीं है। इस पृष्ठ पर उदाहरण उत्पन्न करने के लिए इस टेम्पलेट का उपयोग नहीं किया गया था।

```text
Create one original icon representing [FUNCTION] from the following written brief only. No reference image or other attachment is needed.
Use [OUTLINE OR FILLED] geometry, [STROKE WEIGHT], [CORNER STYLE] and [PALETTE]. Center the icon on a [BACKGROUND] with a consistent optical size.
Check it at [TARGET PIXEL SIZE]; this creates a new direction and does not match an unseen icon system.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
