# Poster, Thumbnail & Visual Design Prompts · 海报、封面与视觉设计

[All 50 prompts](../prompts.md) · [中文首页](../../README.md) · [English](../../README.en.md)

Create a poster, thumbnail, menu, infographic or logo concept from a clear brief. Some tasks start from a photo; others start from approved copy, data or a design file. Choose the task before choosing an image style.

先给准确标题、文案和信息层级，再指定版式与画面方向。图表数据不让模型补写，Logo 概念也不等于已完成矢量交付或商标检索。

## Choose the right task

Provide the intended size or aspect ratio, the exact text and its priority. Supply original files when a real screenshot, menu item, chart or brand asset must be preserved.
