## Calibre d'affichage

- Les cas avec images de référence affichent tous les aperçus existants selon « Matériaux de référence/Exemples de résultats ».
- Les cas sans images de référence utilisent une seule colonne pour afficher les résultats et indiquent la saisie de texte ou l'aperçu de la saisie à compléter en fonction du rôle matériel réel.
- Les matériaux de référence et les résultats sont utilisés pour illustrer les directions visuelles et ne sont pas garantis de reproduire les mêmes effets.
