## Conserver et modifier / Brief d'édition

- **Préserver / 保留：** Honorez les faits écrits fournis, la formulation exacte et les contraintes.
- **Change / 改变：** Utilisez des contours noirs nets sur du blanc, [DETAIL DENSITY] et un [COMPOSITION] équilibré. Fermez les formes proprement et laissez les zones suffisamment grandes pour être colorées ; pas d'ombrage ni de remplissage gris.

## Public prompt

**Modèle public nouvellement compilé · Nouvellement rédigé · Non testé par génération.** Remplacez simplement les paramètres entre crochets, pas besoin de télécharger des images de référence. Ce modèle n'a pas été utilisé pour générer les exemples sur cette page.

```text
Create one adult coloring page about [THEME] from the following written brief only. No reference image or other attachment is needed.
Use crisp black outlines on white, [DETAIL DENSITY] and a balanced [COMPOSITION]. Close shapes cleanly and leave regions large enough to color; no shading or gray fill.
Check broken lines, unfillable slivers and print margins; this run delivers one page, not a whole book.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
