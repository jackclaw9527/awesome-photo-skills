## Que préparer/Intrants

| Matériel | Type / Type | Quantité / Quantité | Condition / Exigence |
| --- | --- | --- | --- |
| Images originales des conférenciers, des exposants ou des objets exposés | Photo/Image | 0-1 ; plusieurs matériaux peuvent être combinés en un seul tableau de référence étiqueté | Facultatif/Facultatif : Lorsque l'affiche doit montrer de vrais conférenciers, exposants ou expositions |
| Titre de l'événement, informations sur le conférencier ou l'exposant, l'heure, le lieu ou la méthode de participation | Caractère / Texte | 1 portion | Obligatoire / Obligatoire |

Cette fois, un seul aperçu visuel est généré. Le calcul des données, la composition précise, les fichiers vectoriels ou de production doivent encore être vérifiés par les outils correspondants.

## Conserver et modifier / Brief d'édition

- **Préserver / 保留：** Conservez les portraits ou les expositions fournis ainsi que tous les noms, titres, organisateurs et faits exacts.
- **Changer / 改变：** Changer la grille, la hiérarchie visuelle, l'arrière-plan, la palette et le traitement de l'image.

## Public prompt

**Modèle public récemment modifié · Nouvellement rédigé · Non testé par génération.** Remplacez les paramètres entre crochets et joignez les matériaux requis dans l'outil qui prend en charge l'édition d'images ; les entrées facultatives et conditionnelles sont préparées selon le tableau ci-dessus. Ce modèle n'a pas été utilisé pour générer les exemples sur cette page.

```text
Create one poster for [CONFERENCE / EXHIBITION / TALK TITLE] using [OPTIONAL APPROVED PORTRAIT OR EXHIBIT IMAGE].
Use only confirmed participant names, roles, organizations, date, time, venue, participation method, and CTA from [EVENT FACTS].
Preserve each supplied person’s identity or each supplied exhibit’s appearance.
Build a formal hierarchy for event title, participant information, logistics, and organizer.
Use [VISUAL DIRECTION], [PALETTE], [FORMAT], and restrained supporting graphics.
Do not invent speakers, credentials, sponsors, institutions, awards, or endorsements.
Keep logos undistorted and use only assets explicitly supplied for this event.
Treat generated lettering as a draft requiring line-by-line proofreading and final typesetting.
Verify print bleed, resolution, accessibility, and channel dimensions in a production tool.
Deliver one event-poster preview image only.
```

## Vérifier les points clés/Revue

Aucun conférencier, organisateur ou soutien fictif n'est fait, et les photos et les textes doivent être confirmés élément par élément.

Relisez les détails et ne fabriquez jamais de conférenciers, de sponsors ou de soutien institutionnel.

Direction des résultats : affiche de la conférence. Lorsque du texte exact, des fichiers transparents, des vecteurs ou une livraison imprimée sont requis, vérifiez le fichier réel ; les fonctionnalités disponibles et les frais sont sujets à la description du site Web.
