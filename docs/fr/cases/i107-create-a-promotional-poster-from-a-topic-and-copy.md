## Conserver et modifier / Brief d'édition

- **Préserver / 保留：** Gardez les personnes, les produits, les œuvres d'art, les marques et les faits fournis exacts.
- **Changement / 改变：** Modifiez la mise en page, l'arrière-plan, le traitement de l'image, la hiérarchie et le système décoratif.

## Public prompt

**Modèle public récemment modifié · Nouvellement rédigé · Non testé par génération.** Remplacez les paramètres entre crochets et joignez les matériaux requis dans l'outil qui prend en charge l'édition d'images ; les entrées facultatives et conditionnelles sont préparées selon le tableau ci-dessus. Ce modèle n'a pas été utilisé pour générer les exemples sur cette page.

```text
Create one promotional poster for [EVENT NAME] using [OPTIONAL APPROVED KEY VISUAL].
Use only these confirmed facts: [CORE MESSAGE], [DATE AND TIME], [LOCATION OR PARTICIPATION METHOD], and [CTA].
Preserve any supplied person, product, artwork, or brand mark without redesigning it.
Build a clear hierarchy for event name, message, logistics, and call to action.
Use [POSTER STYLE], [PALETTE], [IMAGE TREATMENT], and [FORMAT OR ASPECT RATIO].
Do not invent sponsors, speakers, endorsements, prices, availability, or event details.
Keep all exact wording readable and separate from decorative imagery.
Treat generated lettering as a visual draft requiring manual proofreading and final typesetting.
Verify bleed, resolution, color mode, accessibility, and output dimensions in a production tool when printing.
Deliver one poster preview image only.
```

## Vérifier les points clés/Revue

L'heure, le lieu, le mode de participation et le nom de l'événement sont vérifiés un par un. Le diagramme généré ne peut pas remplacer la vérification finale de la mise en page.

Relisez chaque détail de l'événement et reconstruisez des fichiers de type précis ou imprimez-les séparément.

Direction du résultat : affiche de l'événement. Lorsque du texte exact, des fichiers transparents, des vecteurs ou une livraison imprimée sont requis, vérifiez le fichier réel ; les fonctionnalités disponibles et les frais sont sujets à la description du site Web.
