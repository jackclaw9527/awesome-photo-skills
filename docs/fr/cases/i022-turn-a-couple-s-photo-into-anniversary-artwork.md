## Conserver et modifier / Brief d'édition

- **Préserver / 保留：** Conservez les identités, les relations, la logique de pose et les noms ou dates confirmés.
- **Modifier / 改变：** Modifiez le support artistique, l'arrière-plan, la palette et les détails de célébration.

## Public prompt

**Modèle public récemment modifié · Nouvellement rédigé · Non testé par génération.** Remplacez les paramètres entre crochets et joignez les matériaux requis dans l'outil qui prend en charge l'édition d'images ; les entrées facultatives et conditionnelles sont préparées selon le tableau ci-dessus. Ce modèle n'a pas été utilisé pour générer les exemples sur cette page.

```text
Create one anniversary artwork from [COUPLE PHOTO].
Preserve both people’s identities, facial proportions, skin tones, hair, and natural relationship.
Keep the pose recognizable unless [POSE CHANGE] is explicitly requested.
Render the scene in [ART MEDIUM OR STYLE] with [PALETTE] and [BACKGROUND].
Add only restrained [FLORAL / SYMBOLIC / DECORATIVE DETAILS] that support the couple.
If provided, use the exact names “[CONFIRMED NAMES]” and date “[CONFIRMED DATE]”.
Do not guess an anniversary number, relationship status, venue, or date.
Avoid replacing either person with a generic idealized face.
Make the composition suitable for [WALL ART / CARD / DIGITAL GIFT].
Deliver one finished image only and mark any rendered text for manual proofreading.
```

## Vérifier les points clés/Revue

Vérifiez d'abord l'identité et la posture des deux parties, puis vérifiez l'expression artistique ; utilisez uniquement des informations confirmées pour les noms et les dates d’anniversaire.

Vérifiez d’abord les deux visages, puis relisez toutes les informations d’anniversaire.

Direction résultat : portrait anniversaire. Lorsque du texte exact, des fichiers transparents, des vecteurs ou une livraison imprimée sont requis, vérifiez le fichier réel ; les fonctionnalités disponibles et les frais sont sujets à la description du site Web.
