## Public prompt

**Modèle public récemment modifié · Nouvellement rédigé · Non testé par génération.** Remplacez les paramètres entre crochets et joignez les matériaux requis dans l'outil qui prend en charge l'édition d'images ; les entrées facultatives et conditionnelles sont préparées selon le tableau ci-dessus. Ce modèle n'a pas été utilisé pour générer les exemples sur cette page.

```text
Create one product-feature infographic from [PRODUCT PHOTO] and [VERIFIED DIMENSIONS, FEATURES, AND SPECIFICATIONS].
Preserve the product’s exact geometry, color, labels, materials, and visible components.
Use a clear [LAYOUT FORMAT] with product image, callout lines, icons, and concise information hierarchy.
Reproduce every supplied number, unit, feature, and qualifier exactly; do not calculate or infer missing values.
Include only these approved claims: [APPROVED CLAIMS].
Use [BRAND PALETTE], [TYPE DIRECTION], and [BACKGROUND] without obscuring the product.
Keep callout lines attached to the correct feature and maintain readable spacing.
Do not invent certifications, compatibility, performance, warranty, or comparative claims.
Treat generated text as a visual draft: manually proofread and typeset the final file.
Deliver one infographic preview image only, not a verified vector or print-production file.
```

## Vérifier les points clés/Revue

Les dimensions, les paramètres et les arguments de vente proviennent des informations utilisateur ; le texte généré doit être examiné élément par élément.

Relisez tout le texte et vérifiez le fichier de production final séparément.

Direction du résultat : infographie produit. Lorsque du texte exact, des fichiers transparents, des vecteurs ou une livraison imprimée sont requis, vérifiez le fichier réel ; les fonctionnalités disponibles et les frais sont sujets à la description du site Web.
