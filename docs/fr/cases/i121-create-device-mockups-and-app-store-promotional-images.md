## Conserver et modifier / Brief d'édition

- **Préserver / 保留：** Conserver le contenu des captures d'écran et toutes les revendications de fonctionnalités approuvées exactes.
- **Modifier / 改变：** Modifiez le cadre, l'arrière-plan, la composition, l'éclairage et le contexte marketing de l'appareil.

## Public prompt

**Modèle public récemment modifié · Nouvellement rédigé · Non testé par génération.** Remplacez les paramètres entre crochets et joignez les matériaux requis dans l'outil qui prend en charge l'édition d'images ; les entrées facultatives et conditionnelles sont préparées selon le tableau ci-dessus. Ce modèle n'a pas été utilisé pour générer les exemples sur cette page.

```text
Create one app device mockup from [ACTUAL APP SCREENSHOT].
Show it on [TARGET DEVICE] and use only the verified feature message “[APPROVED FEATURE CLAIM]”.
Preserve every visible interface element, text, icon, state, and screen proportion from the supplied screenshot.
Fit the screenshot to the display without redrawing, rewriting, or inventing UI.
Use [DEVICE ANGLE], [BACKGROUND], [PALETTE], and [LIGHTING] for [STORE OR WEBSITE USE].
Keep bezels, corners, reflections, perspective, and screen alignment physically coherent.
Do not show features, notifications, ratings, awards, or compatibility not confirmed by the product.
If marketing text is rendered, proofread it and keep it separate from the app UI.
Verify final store dimensions and platform rules outside the generator.
Deliver one mockup preview image only.
```

## Vérifier les points clés/Revue

L'interface et les arguments de vente doivent provenir de produits réels, et l'effet prototype de l'appareil ne signifie pas que les fonctions ont été réalisées.

Vérifiez la lisibilité de l’interface et n’impliquez jamais une fonctionnalité non implémentée.

Direction du résultat : maquette d'application. Lorsque du texte exact, des fichiers transparents, des vecteurs ou une livraison imprimée sont requis, vérifiez le fichier réel ; les fonctionnalités disponibles et les frais sont sujets à la description du site Web.
