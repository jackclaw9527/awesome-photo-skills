## Conserver et modifier / Brief d'édition

- **Préserver / 保留：** Conservez tous les faits, chiffres, ordre, hiérarchie et relations exactement tels que fournis.
- **Modifier / 改变：** Modifier l'iconographie, la mise en page, le codage couleur, le regroupement visuel et l'accentuation.

## Public prompt

**Modèle public récemment modifié · Nouvellement rédigé · Non testé par génération.** Remplacez les paramètres entre crochets et joignez les matériaux requis dans l'outil qui prend en charge l'édition d'images ; les entrées facultatives et conditionnelles sont préparées selon le tableau ci-dessus. Ce modèle n'a pas été utilisé pour générer les exemples sur cette page.

```text
Create one infographic from [VERIFIED FACTS, STRUCTURE, AND RELATIONSHIPS] and [OPTIONAL STRUCTURE SKETCH].
Preserve every supplied fact, number, unit, sequence, category, and relationship exactly.
Use [FLOW / HIERARCHY / COMPARISON / TIMELINE] as the primary information structure.
Design a clear visual hierarchy with [PALETTE], consistent icons, labels, and generous spacing.
Connect elements only according to the supplied relationships; do not infer missing links.
Do not invent statistics, causes, conclusions, citations, or categories.
Keep text concise but do not paraphrase terms whose exact wording matters.
Treat generated lettering, charts, and symbols as a draft requiring factual and typographic review.
Rebuild precise charts, vectors, and accessible text in an appropriate production tool.
Deliver one infographic preview image only.
```

## Vérifier les points clés/Revue

Les relations, l'ordre et les numéros proviennent des informations fournies. Le caractère raisonnable sur le plan visuel ne signifie pas que les faits sont exacts.

Valider les informations de manière indépendante ; la cohérence visuelle n’est pas une preuve factuelle.

Direction du résultat : infographie. Lorsque du texte exact, des fichiers transparents, des vecteurs ou une livraison imprimée sont requis, vérifiez le fichier réel ; les fonctionnalités disponibles et les frais sont sujets à la description du site Web.
