## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احترام الحقائق المكتوبة المقدمة والصياغة الدقيقة والقيود.
- **التغيير / الصورة:** قم بتصوير [CURRENT PAGE SCENE] باستخدام [SIMPLE CHARACTER DESCRIPTION]، وحدود سوداء سميكة، ومناطق مغلقة كبيرة، وخلفية بيضاء. احترام [PAGE SIZE AND SAFE MARGINS].

## Public prompt

**قالب عام تم تجميعه حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال.** ما عليك سوى استبدال معلمات القوس المربع، دون الحاجة إلى تحميل صور مرجعية. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one interior coloring page for [BOOK THEME] and [TARGET AGE] from the following written brief only. No reference image or other attachment is needed.
Depict [CURRENT PAGE SCENE] with [SIMPLE CHARACTER DESCRIPTION], thick black outlines, large closed regions and a white background. Respect [PAGE SIZE AND SAFE MARGINS].
No cover, page grid or complete book in this run; review age suitability, line continuity and print dimensions.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
