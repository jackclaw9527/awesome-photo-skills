## ما يجب إعداده/المدخلات

**إنشاء نص خالص / نص فقط: لا يلزم وجود صورة أو شعار أو رسم تخطيطي أو أي مرفق آخر. ** استخدم فقط ملخص النص أدناه لإنشاء مفاهيم جديدة.

يتم إنشاء صورة واحدة فقط في كل مرة، ولا حاجة لتحميل الصور. لا ينطبق تحديد الصورة المرجعية لشروط الموقع.

## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احترام الحقائق المكتوبة المقدمة والصياغة الدقيقة والقيود.
- **التغيير / 改变:** إظهار طرق العرض الأمامية والجانبية والخلفية لنفس الشخصية على ورقة واحدة. أصلح [FACE FEATURES] و[BODY PROPORTIONS] و[COSTUME DETAILS] و[PALETTE] عبر طرق العرض الثلاثة جميعها.

## Public prompt

**قالب عام تم تجميعه حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال.** ما عليك سوى استبدال معلمات القوس المربع، دون الحاجة إلى تحميل صور مرجعية. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one character sheet for a new fictional [CHARACTER DESCRIPTION] from the following written brief only. No reference image or other attachment is needed.
Show front, side and back views of the same character on one sheet. Fix [FACE FEATURES], [BODY PROPORTIONS], [COSTUME DETAILS] and [PALETTE] across all three views.
This establishes a new character; check view consistency and avoid inventing an unseen existing identity.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
