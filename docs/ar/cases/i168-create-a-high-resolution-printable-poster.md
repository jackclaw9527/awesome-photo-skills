## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احترام الحقائق المكتوبة المقدمة والصياغة الدقيقة والقيود.
- **التغيير / التعليق:** استخدم [FOCAL SUBJECT] و[PALETTE] و[LAYOUT] و[TARGET ASPECT RATIO]. قم بتضمين "[EXACT WORDING OR NO TEXT]" فقط واحتفظ بالمحتوى المهم ضمن [SAFE MARGINS].

## Public prompt

**قالب عام تم تجميعه حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال.** ما عليك سوى استبدال معلمات القوس المربع، دون الحاجة إلى تحميل صور مرجعية. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one poster artwork for [THEME AND DISPLAY CONTEXT] from the following written brief only. No reference image or other attachment is needed.
Use [FOCAL SUBJECT], [PALETTE], [LAYOUT] and [TARGET ASPECT RATIO]. Include only “[EXACT WORDING OR NO TEXT]” and keep critical content within [SAFE MARGINS].
Check actual pixel dimensions, typography, bleed and a physical proof; prompting alone cannot guarantee print resolution.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
