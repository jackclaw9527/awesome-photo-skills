## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احتفظ بالأشخاص والمنتجات والأعمال الفنية والعلامات التجارية وحقائق الأحداث الموردة بدقة.
- **التغيير / الصورة:** تغيير التخطيط والخلفية ومعالجة الصور والتسلسل الهرمي ونظام الزخرفة.

## Public prompt

**قالب عام تم تحريره حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال. ** استبدل معلمات القوس المربع وأرفق المواد المطلوبة في الأداة التي تدعم تحرير الصور؛ يتم إعداد المدخلات الاختيارية والشرطية حسب الجدول أعلاه. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one promotional poster for [EVENT NAME] using [OPTIONAL APPROVED KEY VISUAL].
Use only these confirmed facts: [CORE MESSAGE], [DATE AND TIME], [LOCATION OR PARTICIPATION METHOD], and [CTA].
Preserve any supplied person, product, artwork, or brand mark without redesigning it.
Build a clear hierarchy for event name, message, logistics, and call to action.
Use [POSTER STYLE], [PALETTE], [IMAGE TREATMENT], and [FORMAT OR ASPECT RATIO].
Do not invent sponsors, speakers, endorsements, prices, availability, or event details.
Keep all exact wording readable and separate from decorative imagery.
Treat generated lettering as a visual draft requiring manual proofreading and final typesetting.
Verify bleed, resolution, color mode, accessibility, and output dimensions in a production tool when printing.
Deliver one poster preview image only.
```

## تحقق من النقاط الرئيسية/المراجعة

يتم التحقق من الوقت والموقع وطريقة المشاركة واسم الحدث واحدًا تلو الآخر. لا يمكن للرسم التخطيطي الذي تم إنشاؤه أن يحل محل فحص التخطيط النهائي.

قم بمراجعة كل تفاصيل الحدث وإعادة إنشاء الملفات الدقيقة أو طباعة الملفات بشكل منفصل.

اتجاه النتيجة: ملصق الحدث. عندما يكون النص الدقيق أو الملفات الشفافة أو المتجهات أو تسليم الطباعة مطلوبًا، تحقق من الملف الفعلي؛ الميزات والرسوم المتاحة تخضع لوصف الموقع.
