## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احترام الحقائق المكتوبة المقدمة والصياغة الدقيقة والقيود.
- **التغيير / 改变:** استخدم [MOTIFS] الأصلي المناسب للعمر وتسلسل هرمي قابل للقراءة لـ "[TITLE]" و"[DATE]" و"[LOCATION]" و"[PARTICIPATION DETAILS]". استخدم [PALETTE] و[FORMAT].

## Public prompt

**قالب عام تم تجميعه حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال.** ما عليك سوى استبدال معلمات القوس المربع، دون الحاجة إلى تحميل صور مرجعية. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one poster for [SCHOOL EVENT OR COURSE] aimed at [AGE GROUP] from the following written brief only. No reference image or other attachment is needed.
Use age-appropriate original [MOTIFS] and a readable hierarchy for “[TITLE]”, “[DATE]”, “[LOCATION]” and “[PARTICIPATION DETAILS]”. Use [PALETTE] and [FORMAT].
Do not invent school emblems, staff identities or approval claims; verify every event fact.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
