## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احتفظ بالصور أو المعروضات المقدمة وجميع الأسماء والألقاب والمنظمين والحقائق بدقة.
- **التغيير / الصورة:** تغيير الشبكة والتسلسل الهرمي المرئي والخلفية ولوحة الألوان ومعالجة الصور.

## Public prompt

**قالب عام تم تحريره حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال. ** استبدل معلمات القوس المربع وأرفق المواد المطلوبة في الأداة التي تدعم تحرير الصور؛ يتم إعداد المدخلات الاختيارية والشرطية حسب الجدول أعلاه. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one poster for [CONFERENCE / EXHIBITION / TALK TITLE] using [OPTIONAL APPROVED PORTRAIT OR EXHIBIT IMAGE].
Use only confirmed participant names, roles, organizations, date, time, venue, participation method, and CTA from [EVENT FACTS].
Preserve each supplied person’s identity or each supplied exhibit’s appearance.
Build a formal hierarchy for event title, participant information, logistics, and organizer.
Use [VISUAL DIRECTION], [PALETTE], [FORMAT], and restrained supporting graphics.
Do not invent speakers, credentials, sponsors, institutions, awards, or endorsements.
Keep logos undistorted and use only assets explicitly supplied for this event.
Treat generated lettering as a draft requiring line-by-line proofreading and final typesetting.
Verify print bleed, resolution, accessibility, and channel dimensions in a production tool.
Deliver one event-poster preview image only.
```

## تحقق من النقاط الرئيسية/المراجعة

لا يتم إجراء أي متحدثين أو منظمين أو موافقات وهمية، ويجب تأكيد الصور والنصوص بندًا بندًا.

قم بتدقيق التفاصيل وعدم اختلاق المتحدثين أو الجهات الراعية أو الدعم المؤسسي أبدًا.

اتجاه النتائج: ملصق المؤتمر. عندما يكون النص الدقيق أو الملفات الشفافة أو المتجهات أو تسليم الطباعة مطلوبًا، تحقق من الملف الفعلي؛ الميزات والرسوم المتاحة تخضع لوصف الموقع.
