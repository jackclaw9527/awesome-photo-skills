## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احترام الحقائق المكتوبة المقدمة والصياغة الدقيقة والقيود.
- **التغيير / 改变:** الشخصية هي [SPECIES] و[CLASS] و[BACKSTORY] و[PERSONALITY] و[VISIBLE FEATURES] و[EQUIPMENT]. استخدم [MEDIUM] و[LIGHTING] و[SETTING] للتعبير عن دورهم.

## Public prompt

**قالب عام تم تجميعه حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال.** ما عليك سوى استبدال معلمات القوس المربع، دون الحاجة إلى تحميل صور مرجعية. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one portrait of an original tabletop character from the following written brief only. No reference image or other attachment is needed.
The character is [SPECIES], [CLASS], with [BACKSTORY], [PERSONALITY], [VISIBLE FEATURES] and [EQUIPMENT]. Use [MEDIUM], [LIGHTING] and [SETTING] to express their role.
Keep anatomy and equipment coherent; create a new fictional identity without requiring a player photo.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
