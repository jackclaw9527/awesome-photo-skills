## الاحتفاظ والتغيير/التحرير الموجز

- **الحفاظ / 保留:** احترام الحقائق المكتوبة المقدمة والصياغة الدقيقة والقيود.
- **التغيير / 改变:** ترتيب الزخارف في [DENSITY AND SCALE] على [GROUND COLOR]، مع [PALETTE] و[DRAWING STYLE]. قم بمطابقة الحواف المتعارضة بحيث تستمر الزخارف عبر الحدود.

## Public prompt

**قالب عام تم تجميعه حديثًا · مؤلف حديثًا · لم يتم اختباره بواسطة الأجيال.** ما عليك سوى استبدال معلمات القوس المربع، دون الحاجة إلى تحميل صور مرجعية. لم يتم استخدام هذا القالب لإنشاء الأمثلة في هذه الصفحة.

```text
Create one seamless fabric-print tile featuring [MOTIFS] from the following written brief only. No reference image or other attachment is needed.
Arrange motifs at [DENSITY AND SCALE] on [GROUND COLOR], with [PALETTE] and [DRAWING STYLE]. Match opposing edges so motifs continue across the boundary.
Test a 3-by-3 repeat for seams, accidental stripes and awkward gaps before fabric production.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
