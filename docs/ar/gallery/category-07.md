## I262 · قم بإنشاء رسوم توضيحية للتقارير السنوية أو دراسات الحالة

<p><strong>مثال على النتائج</strong></p>
<p><a href="https://dearsketch.com/ar/intent/i262-create-illustrations-for-an-annual-report-white-paper-or-case-study.html?utm_source=github&amp;utm_medium=gallery&amp;utm_campaign=dearsketch-public-cases&amp;utm_content=i262_image"><img src="../../../assets/cases/i262-after.webp" alt="قم بإنشاء رسوم توضيحية للتقرير السنوي أو دراسة الحالة - نتائج الأمثلة" width="340"></a></p>

- **نوع الإدخال:** يعرض هذا المثال أمثلة النتائج فقط؛ تتم إضافة معاينة إدخال الصورة
- **متطلبات المواد:** مواصفات العلامة التجارية الاختيارية أو نقاط التثبيت التوضيحية للتقرير الحالي (0 إلى متعدد) + قائمة الفصول المطلوبة وملخص كل فصل (نسخة واحدة) + بيانات التحقق من الحالة (نسخة واحدة) + مواصفات العلامة التجارية الاختيارية (0 أو نسخة واحدة)
- **الوصف:** يتم إنشاء الخيار المحدد حاليًا فقط في كل مرة؛ يتم تنفيذ الصور الأخرى في السلسلة بشكل منفصل.
