# 直接試すことができる 5 つの基本テンプレート

[中文](../../README.md) · [English](../../README.en.md) · [Português](../../README.pt.md) · [Español](../../README.es.md) · [Français](../../README.fr.md) · [Deutsch](../../README.de.md) · [عربي](../../README.ar.md) · [русский](../../README.ru.md) · [日本語](../../README.ja.md) · [हिंदी](../../README.hi.md)


ここでは、パブリック コンテンツ ライブラリ用に個別に作成された 5 つの基本テンプレートを示します。自分の素材をアップロードした後、参考画像編集をサポートするツールに対応するテキストを与えると試すことができます。ツールが異なれば、入力方法、コスト、利用可能な機能も異なります。使用したツールの説明を参照してください。

これらのテンプレートは、Web サイトのプライベート スキルからエクスポートされたものではなく、このリポジトリ内の既存のサンプル ダイアグラムを生成するために使用されたものでもありません。これらはテンプレートごとのモデルでテストされておらず、サンプル図を再現することは保証されていません。サンプル図はチュートリアル テンプレートとは別にマークされています。

## ペットのカスタムポートレート1枚

ペットの目、耳、主な模様がわかる写真をご用意ください。次の例では、クリエイティブな方向として温かみのある白の背景とシンプルなイラストを選択しています。これは自分で置き換えることができます。

```text
请以所附照片中的同一只宠物为主体，制作一张简洁的宠物肖像插画。
保留照片里可见的脸部结构、眼睛颜色、耳朵形状和主要花纹，
不要把它替换成另一只相似品种的宠物。
使用暖白背景、柔和色块和少量线条，让主体清楚、构图留有呼吸空间。
不添加姓名、日期、服饰、配件或水印。只输出一张最终肖像。
```

パターンが一致していること、耳が損傷していないこと、同じペットであることを認識していることを確認してください。

## 2 実際の写真を漫画のアバターに変換します

鮮明なポートレートを準備します。フラットな色のブロックを特徴とするこの基本的なテンプレートは、特定の作品やアーティストの表現を複製する必要はありません。

```text
把所附照片中的人物转换成原创的卡通头像。
保留可识别的脸型、发型和照片里确实存在的配饰。
用清楚的轮廓、简洁色块和克制的阴影表达人物，背景保持单纯。
不要改变人物年龄观感，不加入照片中不存在的职业、身份或品牌元素。
头部和肩部构图，不加文字和水印，只输出一张头像。
```

キャラクターが認識できること、髪のエッジ、メガネ、耳が自然に見えることを確認してください。

## 3 住宅用水彩記念絵画

主要な外観がわかる家の写真を用意します。写真で確認できる建物情報のみを描画します。

```text
根据所附房屋照片制作一张水彩风格的住宅纪念画。
保留房屋的主要轮廓、屋顶、门窗位置和可见结构。
用轻薄的水彩色层和少量线条表达建筑，周围保留适量空白。
不增加照片看不到的新楼层、门牌、文字或虚构建筑装饰。
背景可以适度简化，但不要把原房屋改成另一栋建筑。只输出一张画。
```

まず、水彩表現を屋根、窓、入り口の位置と照らし合わせて確認します。

## 4 製品メイン画像（背景白）

製品の鮮明な写真をご用意ください。透明、反射、小さな中空の構造には特別な検査が必要です。

```text
把所附照片中的同一件商品整理成干净的白底商品展示图。
保持商品本身的形状、比例、颜色、标签和可见细节，不更换商品型号。
移除与商品无关的背景杂物，让商品完整入画，边缘自然。
不要添加新的标签、卖点、品牌、配件或认证标记。
不添加装饰边框和文字，只输出一张最终商品图。
```

小端やラベルを確認し、実際の販売チャネルに応じてサイズ、余白、メイン画像の仕様を確認してください。

## 5 ロゴコンセプトの探求

括弧内の内容を独自のブランド資料に置き換えてください。ここではグラフィックのコンセプトが要求されますが、ベクター ファイルや商標の登録可能性については保証されません。

```text
为一个[品牌领域]品牌探索一个原创图形标志概念。
品牌定位是[一句话定位]，主要面向[目标人群]。
用简洁形状表达[一个核心意象]，选择[主色]搭配中性色。
先只展示一个不含文字的图形标志，居中放在纯净背景上。
不要套用现有品牌标志，不加样机、装饰场景、口号或水印。
只输出一张概念图。
```

ズームアウトしてまだ鮮明かどうかを確認し、ワードマーク、ベクトル配置、使用シナリオの検証を行います。

## テンプレートから独自の結果まで

まず、主題と事実が正しいかどうかを確認する小規模な試みを完了し、次に絵画スタイル、構図、その他の変数を変更します。名前、価格、サイズ、イベントの日付、正確なコピーライティングに遭遇した場合は、それらを一字一句確認し、モデルに入力させないでください。

特定のタスクごとの入力要件を表示したい場合は、[50 ケース ディレクトリ ](./prompts.md) から Web サイトの対応するページにアクセスできます。
