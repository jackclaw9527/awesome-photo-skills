## Сохранить и изменить / Краткое описание редактирования

- **Сохранить / 保留：** Соблюдайте предоставленные письменные факты, точные формулировки и ограничения.
- **Изменить / Добавить:** Создайте [BOX OR CONTAINER STRUCTURE] для [CHANNEL AND POSITIONING]. Покажите одну основную упаковку и ограниченный контекст полки; используйте только «[BRAND NAME]» и «[EXACT COPY]».

## Public prompt

**Недавно скомпилированный общедоступный шаблон · Недавно созданный · Не проверен поколением.** Просто замените параметры в квадратных скобках, не нужно загружать эталонные изображения. Этот шаблон не использовался для создания примеров на этой странице.

```text
Create one packaging-and-shelf concept for a fictional [PRODUCT CATEGORY] from the following written brief only. No reference image or other attachment is needed.
Design [BOX OR CONTAINER STRUCTURE] for [CHANNEL AND POSITIONING]. Show one main pack and a restrained shelf context; use only “[BRAND NAME]” and “[EXACT COPY]”.
Keep repeated packs consistent; do not imply a tested dieline, shelf load rating or actual stocked product.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```

## Проверьте ключевые моменты/обзор

Следите за тем, чтобы повторные упаковки были одинаковыми; не подразумевают проверенную технологическую линию, номинальную нагрузку на полку или фактическое наличие продукта на складе.
