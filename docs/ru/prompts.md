# Рекомендации по редактированию фотографий с помощью AI · 50 общедоступных шаблонов для обработки фотографий

Выберите шаблон в зависимости от задачи, которую вы хотите выполнить. В каждом ящике содержатся полные слова-подсказки на английском языке, требования к материалам на китайском языке и контрольные точки. Все шаблоны представляют собой недавно скомпилированный контент в этой библиотеке и не тестировались по отдельности. Они не являются оригинальными инструкциями по созданию существующей демонстрационной графики.

Выберите задачу, откройте ее корпус и замените заполнители в квадратных скобках. Эти недавно созданные шаблоны не тестировались на уровне поколений. Расширенная галерея не включает подсказки.
