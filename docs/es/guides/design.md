# Póster, miniaturas y indicaciones de diseño visual · Póster, portada y diseño visual

[中文](../../../README.md) · [English](../../../README.en.md) · [Português](../../../README.pt.md) · [Español](../../../README.es.md) · [Français](../../../README.fr.md) · [Deutsch](../../../README.de.md) · [عربي](../../../README.ar.md) · [русский](../../../README.ru.md) · [日本語](../../../README.ja.md) · [हिंदी](../../../README.hi.md)


Cree un concepto de póster, miniatura, menú, infografía o logotipo a partir de un resumen claro. Algunas tareas parten de una foto; otros parten de una copia aprobada, datos o un archivo de diseño. Elija la tarea antes de elegir un estilo de imagen.

Primero proporcione el título, la copia y el nivel de información correctos, y luego especifique el diseño y la dirección de la pantalla. Los datos del gráfico no permiten reescribir el modelo y el concepto del logotipo no significa que se haya completado la entrega del vector o la búsqueda de marcas.

## Elige la tarea correcta

Proporcione el tamaño o relación de aspecto deseado, el texto exacto y su prioridad. Proporcione archivos originales cuando deba conservarse una captura de pantalla, un elemento de menú, un gráfico o un activo de marca real.
