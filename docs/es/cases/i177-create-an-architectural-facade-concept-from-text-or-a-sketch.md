Sólo se genera una imagen a la vez.

## Conservar y cambiar / Editar resumen

- **Conservar / 保留：** Mantenga las masas y las aberturas suministradas solo cuando exista un boceto o una referencia de masa.
- **Cambiar / 改变：** Cambiar los materiales de la fachada, la articulación, el entorno, el paisaje y la luz.

**Plantilla pública recién editada · Creación reciente · No probada en generación.** Reemplace los parámetros de corchetes y adjunte los materiales necesarios en la herramienta que admite la edición de imágenes; Las entradas opcionales y condicionales se preparan de acuerdo con la tabla anterior. Esta plantilla no se utilizó para generar los ejemplos de esta página.

```text
Create one architectural facade concept for [BUILDING USE] with [DESIGN KEYWORDS].
Choose one branch: follow [OPTIONAL SKETCH OR MASSING IMAGE] when supplied, or create a text-led concept from the brief when no image exists.
For the reference branch, preserve the supplied massing, floor count, principal openings, roof form, proportions, and camera view.
For the text-only branch, do not claim that any generated geometry reproduces an existing design.
Develop [FACADE MATERIALS], [OPENING TREATMENT], [SHADING ELEMENTS], and [ENTRY EXPRESSION].
Add a restrained [SITE CONTEXT], [LANDSCAPE], and [LIGHTING CONDITION] for scale.
Keep perspective, material joints, shadows, and human scale coherent.
Do not invent planning approval, structural feasibility, energy performance, or code compliance.
Do not treat generated details as measured dimensions or construction assemblies.
Deliver one facade concept rendering only for design discussion.
```

## Consulta los puntos clave/Revisión

Se aclaran el propósito del edificio y la dirección del diseño, y los resultados se utilizan para la comunicación conceptual, no para los dibujos de construcción.

Trate el resultado como comunicación conceptual, no como un dibujo para la construcción.

Dirección del resultado: Representación del concepto arquitectónico. Cuando se requiera texto exacto, archivos transparentes, vectores o entrega impresa, verifique el archivo real; Las funciones y tarifas disponibles están sujetas a la descripción del sitio web.
