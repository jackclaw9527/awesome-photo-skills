## Conservar y cambiar / Editar resumen

- **Conservar / 保留：** Mantenga los colores de referencia suministrados y las identidades de los materiales solo cuando existan referencias.
- **Cambiar / 改变：** Cambie el diseño, la jerarquía, los recortes, las anotaciones y admita las muestras generadas.

## Public prompt

**Plantilla pública recién editada · Creación reciente · No probada en generación.** Reemplace los parámetros de corchetes y adjunte los materiales necesarios en la herramienta que admite la edición de imágenes; Las entradas opcionales y condicionales se preparan de acuerdo con la tabla anterior. Esta plantilla no se utilizó para generar los ejemplos de esta página.

```text
Create one mood board for [PROJECT TYPE] using [DESIGN KEYWORDS].
Choose one branch: organize [OPTIONAL REFERENCE BOARD OR LABELED IMAGES] when supplied, or develop a text-led direction when no references exist.
For the reference branch, preserve recognizable colors, textures, material identities, and atmosphere.
For the text-only branch, use [PALETTE], [MATERIAL DIRECTION], [FORM LANGUAGE], and [LIGHTING MOOD] without implying specific sourced products.
Use a clear [EDITORIAL / MATERIAL-LIBRARY / COLLAGE] hierarchy with clean spacing.
Label only confirmed generic material names or exact product names supplied by the user.
Do not invent manufacturers, product codes, prices, availability, dimensions, or performance claims.
Do not imply that visually similar generated materials are actual specified products.
Treat the board as direction-setting inspiration; procurement and physical samples require separate confirmation.
Deliver one self-contained mood-board image only.
```

## Consulta los puntos clave/Revisión

El moodboard es para comunicación de diseño, no para una lista de compras; Es necesario confirmar los productos, tamaños y precios específicos.

Trate el tablero como inspiración, no como un producto confirmado o una lista de adquisiciones.

Resultados en la dirección de: Mood Board. Cuando se requiera texto exacto, archivos transparentes, vectores o entrega impresa, verifique el archivo real; Las funciones y tarifas disponibles están sujetas a la descripción del sitio web.
