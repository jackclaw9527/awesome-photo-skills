## Conservar y cambiar / Editar resumen

- **Preservar / 保留：** Respete los hechos escritos proporcionados, la redacción exacta y las limitaciones.
- **Cambiar / 改变：** Construya la imagen a partir de formas cerradas simples, [PALETTE] y superposiciones limpias. Utilice [COMPOSITION] y evite el grano, los degradados y los pequeños detalles que complican el trazado.

## Public prompt

**Plantilla pública recién compilada · De nueva creación · No probada en generación.** Simplemente reemplace los parámetros de corchetes, no es necesario cargar imágenes de referencia. Esta plantilla no se utilizó para generar los ejemplos de esta página.

```text
Create one vector-style illustration about [SUBJECT] for [USE] from the following written brief only. No reference image or other attachment is needed.
Build the image from simple closed shapes, [PALETTE] and clean overlaps. Use [COMPOSITION] and avoid grain, gradients and tiny details that complicate tracing.
A raster preview is not an editable SVG; inspect and rebuild paths in a vector editor if needed.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
