## Conservar y cambiar / Editar resumen

- **Preserve / 保留：** Mantenga exactos el contenido de las capturas de pantalla y todas las funciones aprobadas.
- **Cambiar / 改变：** Cambie el marco del dispositivo, el fondo, la composición, la iluminación y el contexto de marketing.

## Public prompt

**Plantilla pública recién editada · Creación reciente · No probada en generación.** Reemplace los parámetros de corchetes y adjunte los materiales necesarios en la herramienta que admite la edición de imágenes; Las entradas opcionales y condicionales se preparan de acuerdo con la tabla anterior. Esta plantilla no se utilizó para generar los ejemplos de esta página.

```text
Create one app device mockup from [ACTUAL APP SCREENSHOT].
Show it on [TARGET DEVICE] and use only the verified feature message “[APPROVED FEATURE CLAIM]”.
Preserve every visible interface element, text, icon, state, and screen proportion from the supplied screenshot.
Fit the screenshot to the display without redrawing, rewriting, or inventing UI.
Use [DEVICE ANGLE], [BACKGROUND], [PALETTE], and [LIGHTING] for [STORE OR WEBSITE USE].
Keep bezels, corners, reflections, perspective, and screen alignment physically coherent.
Do not show features, notifications, ratings, awards, or compatibility not confirmed by the product.
If marketing text is rendered, proofread it and keep it separate from the app UI.
Verify final store dimensions and platform rules outside the generator.
Deliver one mockup preview image only.
```

## Consulta los puntos clave/Revisión

La interfaz y los puntos de venta deben provenir de productos reales, y el efecto de prototipo del dispositivo no significa que las funciones se hayan realizado.

Verifique la legibilidad de la interfaz y nunca dé a entender una característica no implementada.

Dirección del resultado: Maqueta de aplicación. Cuando se requiera texto exacto, archivos transparentes, vectores o entrega impresa, verifique el archivo real; Las funciones y tarifas disponibles están sujetas a la descripción del sitio web.
