## Conservar y cambiar / Editar resumen

- **Preservar / 保留：** Mantenga exactos los retratos o exhibiciones suministrados y todos los nombres, títulos, organizadores y hechos.
- **Cambiar / 改变：** Cambie la cuadrícula, la jerarquía visual, el fondo, la paleta y el tratamiento de la imagen.

## Public prompt

**Plantilla pública recién editada · Creación reciente · No probada en generación.** Reemplace los parámetros de corchetes y adjunte los materiales necesarios en la herramienta que admite la edición de imágenes; Las entradas opcionales y condicionales se preparan de acuerdo con la tabla anterior. Esta plantilla no se utilizó para generar los ejemplos de esta página.

```text
Create one poster for [CONFERENCE / EXHIBITION / TALK TITLE] using [OPTIONAL APPROVED PORTRAIT OR EXHIBIT IMAGE].
Use only confirmed participant names, roles, organizations, date, time, venue, participation method, and CTA from [EVENT FACTS].
Preserve each supplied person’s identity or each supplied exhibit’s appearance.
Build a formal hierarchy for event title, participant information, logistics, and organizer.
Use [VISUAL DIRECTION], [PALETTE], [FORMAT], and restrained supporting graphics.
Do not invent speakers, credentials, sponsors, institutions, awards, or endorsements.
Keep logos undistorted and use only assets explicitly supplied for this event.
Treat generated lettering as a draft requiring line-by-line proofreading and final typesetting.
Verify print bleed, resolution, accessibility, and channel dimensions in a production tool.
Deliver one event-poster preview image only.
```

## Consulta los puntos clave/Revisión

No se hacen oradores, organizadores ni patrocinios ficticios, y las fotografías y el texto deben confirmarse artículo por artículo.

Revise los detalles y nunca fabrique oradores, patrocinadores o respaldo institucional.

Dirección de Resultados: Afiche de conferencia. Cuando se requiera texto exacto, archivos transparentes, vectores o entrega impresa, verifique el archivo real; Las funciones y tarifas disponibles están sujetas a la descripción del sitio web.
