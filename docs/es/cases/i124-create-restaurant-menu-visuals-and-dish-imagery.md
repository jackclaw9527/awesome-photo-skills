## Conservar y cambiar / Editar resumen

- **Conservar / 保留：** Mantenga exactos todos los datos del menú y la apariencia real del plato.
- **Cambiar / 改变：** Cambie el diseño, el fondo, el sistema decorativo, los recortes de imágenes y la jerarquía.

Create one restaurant menu visual using [CONFIRMED DISH NAMES, PRICES, AND CATEGORIES] and [OPTIONAL REAL DISH PHOTO].

Reproduce every dish name, price, currency, qualifier, and category exactly.

## Consulta los puntos clave/Revisión

El precio, el nombre y la categoría deben confirmarse uno por uno, y distinguirse claramente entre las fotografías de los platos reales y las instrucciones creativas.

Revise cada nombre y precio y distinga las fotografías reales de platos de los conceptos ilustrativos.

Dirección de Resultados: Menú. Cuando se requiera texto exacto, archivos transparentes, vectores o entrega impresa, verifique el archivo real; Las funciones y tarifas disponibles están sujetas a la descripción del sitio web.
