## Conservar y cambiar / Editar resumen

- **Preservar / 保留：** Respete los hechos escritos proporcionados, la redacción exacta y las limitaciones.
- **Cambiar / 改变：** Utilice [PROPORTIONS], [BODY LANGUAGE], [MATERIALS] y [COLOR] para [USE CASE]. Muestre una vista coherente de tres cuartos con una alineación de ruedas creíble y una geometría de panel consistente.
