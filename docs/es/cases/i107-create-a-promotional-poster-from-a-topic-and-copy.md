## Conservar y cambiar / Editar resumen

- **Preservar / 保留：** Mantenga exactas las personas, productos, obras de arte, marcas y datos de eventos suministrados.
- **Cambiar / 改变：** Cambie el diseño, el fondo, el tratamiento de la imagen, la jerarquía y el sistema decorativo.

## Public prompt

**Plantilla pública recién editada · Creación reciente · No probada en generación.** Reemplace los parámetros de corchetes y adjunte los materiales necesarios en la herramienta que admite la edición de imágenes; Las entradas opcionales y condicionales se preparan de acuerdo con la tabla anterior. Esta plantilla no se utilizó para generar los ejemplos de esta página.

```text
Create one promotional poster for [EVENT NAME] using [OPTIONAL APPROVED KEY VISUAL].
Use only these confirmed facts: [CORE MESSAGE], [DATE AND TIME], [LOCATION OR PARTICIPATION METHOD], and [CTA].
Preserve any supplied person, product, artwork, or brand mark without redesigning it.
Build a clear hierarchy for event name, message, logistics, and call to action.
Use [POSTER STYLE], [PALETTE], [IMAGE TREATMENT], and [FORMAT OR ASPECT RATIO].
Do not invent sponsors, speakers, endorsements, prices, availability, or event details.
Keep all exact wording readable and separate from decorative imagery.
Treat generated lettering as a visual draft requiring manual proofreading and final typesetting.
Verify bleed, resolution, color mode, accessibility, and output dimensions in a production tool when printing.
Deliver one poster preview image only.
```

## Consulta los puntos clave/Revisión

La hora, la ubicación, el método de participación y el nombre del evento se verifican uno por uno. El diagrama generado no puede reemplazar la verificación del diseño final.

Revise cada detalle del evento y reconstruya tipos precisos o imprima archivos por separado.

Dirección del resultado: cartel del evento. Cuando se requiera texto exacto, archivos transparentes, vectores o entrega impresa, verifique el archivo real; Las funciones y tarifas disponibles están sujetas a la descripción del sitio web.
