# Poster, Miniaturansichten und visuelle Gestaltungsvorgaben · Poster, Cover und visuelle Gestaltung

Erstellen Sie aus einem klaren Briefing ein Poster-, Miniaturbild-, Menü-, Infografik- oder Logo-Konzept. Manche Aufgaben beginnen mit einem Foto; andere beginnen mit einer genehmigten Kopie, Daten oder einer Designdatei. Wählen Sie die Aufgabe aus, bevor Sie einen Bildstil auswählen.

Geben Sie zunächst den richtigen Titel, Text und Informationsniveau an und geben Sie dann das Layout und die Bildschirmausrichtung an. Diagrammdaten ermöglichen keine Umschreibung des Modells und das Logo-Konzept bedeutet nicht, dass die Vektorlieferung oder Markensuche abgeschlossen ist.

## Wählen Sie die richtige Aufgabe

Geben Sie die gewünschte Größe oder das Seitenverhältnis, den genauen Text und seine Priorität an. Stellen Sie Originaldateien bereit, wenn ein echter Screenshot, ein Menüpunkt, ein Diagramm oder ein Markenwert erhalten bleiben muss.
