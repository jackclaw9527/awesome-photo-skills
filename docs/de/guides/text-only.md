50 vollständige Briefings für neue Kunstwerke und Konzeptbilder. Es ist kein Foto, Logo, Skizze oder Referenzanhang erforderlich.

Für diese 50 Elemente ist nur Text erforderlich. Geben Sie einfach das Thema, den Zweck, den Stil und den genauen Text ein; Sie etablieren ein neues Konzept und versprechen nicht, eine Marke, einen Charakter, ein Produkt oder einen realen Raum fortzuführen, der nicht bereitgestellt wird.

## Wählen Sie die richtige Aufgabe

Wählen Sie ein Briefing, ersetzen Sie alle in Klammern gesetzten Felder und erstellen Sie ein Bild. Ein Vektorstil- oder Druckkonzept erfordert vor der Produktion noch Dateiprüfungen.
