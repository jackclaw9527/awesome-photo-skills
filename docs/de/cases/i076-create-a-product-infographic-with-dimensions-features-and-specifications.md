## Behalten und ändern / Kurzfassung bearbeiten

- **Bewahren / Hinweis:** Achten Sie darauf, dass das Erscheinungsbild des Produkts und jede angegebene Anzahl, Einheit und Angabe genau sind.
- **Ändern / 改变：** Ändern Sie Layout, Beschriftungen, Symbole, Hierarchie und unterstützenden Hintergrund.

## Überprüfen Sie die wichtigsten Punkte/Bewertung

Abmessungen, Parameter und Verkaufsargumente stammen aus Benutzerinformationen; Der generierte Text muss Element für Element überprüft werden.

Lesen Sie den gesamten Text Korrektur und überprüfen Sie die endgültige Produktionsdatei separat.

Ergebnisrichtung: Produktinfografik. Wenn exakter Text, transparente Dateien, Vektoren oder eine Drucklieferung erforderlich sind, überprüfen Sie die tatsächliche Datei. Die verfügbaren Funktionen und Gebühren unterliegen der Beschreibung auf der Website.
