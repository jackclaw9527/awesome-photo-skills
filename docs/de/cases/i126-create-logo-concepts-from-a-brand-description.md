## Was vorzubereiten/Eingaben

| Material | Typ / Typ | Menge / Menge | Bedingung / Anforderung |
| --- | --- | --- | --- |
| Originales Markenlogo und Identitätselemente | Bild/Bild | 0–1; Mehrere Materialien können zu einer beschrifteten Referenztafel kombiniert werden | Optional: Wenn Sie Logoerweiterungen für eine bestehende Marke erkunden, anstatt eine von Grund auf neu zu erstellen |

## Behalten und ändern / Kurzfassung bearbeiten

- **Beibehalten / Hinweis:** Behalten Sie den genauen Markennamen und die bereitgestellten Identitätsressourcen bei; Vermeiden Sie Fremdmarken.
- **Ändern / 改变：** Symbolideen, Buchstabenformrichtung, Geometrie, Farbe und Darstellung ändern.

## Public prompt

**Neu bearbeitete öffentliche Vorlage · Neu verfasst · Nicht generativ getestet.** Ersetzen Sie die Parameter in eckigen Klammern und fügen Sie die erforderlichen Materialien in das Tool ein, das die Bildbearbeitung unterstützt; Optionale und bedingte Eingaben werden gemäß der obigen Tabelle vorbereitet. Diese Vorlage wurde nicht zum Generieren der Beispiele auf dieser Seite verwendet.

```text
Create one logo concept presentation for the exact brand name “[BRAND NAME]”.
Base the concept on [BRAND POSITIONING], [TARGET AUDIENCE], and [BRAND ATTRIBUTES].
If [EXISTING BRAND ASSET] is supplied, preserve its essential identity according to [KEEP / EVOLVE INSTRUCTION].
Explore an original [WORDMARK / SYMBOL / COMBINATION MARK] direction using [FORM LANGUAGE] and [PALETTE].
Keep the mark simple, distinctive, legible, and reproducible at small size.
Do not copy existing logos, protected symbols, or a living designer’s signature work.
Do not invent a slogan; use only “[EXACT TAGLINE]” when supplied.
Present one coherent concept rather than a sheet of unrelated alternatives.
Treat the result as a raster concept: perform trademark research and rebuild approved geometry and type as vectors.
Deliver one logo-concept image only, not final trademark clearance or production files.
```

## Überprüfen Sie die wichtigsten Punkte/Bewertung

Das Ergebnis ist ein Konzeptentwurf, der zusätzliche Verarbeitungsschritte für die Markensuche sowie die Bereitstellung von Glyphen und Vektoren erfordert.

Führen Sie Markenprüfungen durch und erstellen Sie die endgültigen Vektoren und Typografien separat neu.

Ergebnisrichtung: Logo-Entwurf. Wenn exakter Text, transparente Dateien, Vektoren oder eine Drucklieferung erforderlich sind, überprüfen Sie die tatsächliche Datei. Die verfügbaren Funktionen und Gebühren unterliegen der Beschreibung auf der Website.
