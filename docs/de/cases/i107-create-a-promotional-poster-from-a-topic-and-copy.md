## Behalten und ändern / Kurzfassung bearbeiten

- **Preserve / 保留：** Halten Sie die bereitgestellten Personen, Produkte, Kunstwerke, Markenzeichen und Veranstaltungsdaten genau.
- **Ändern / 改变：** Ändern Sie Layout, Hintergrund, Bildbehandlung, Hierarchie und dekoratives System.

## Public prompt

**Neu bearbeitete öffentliche Vorlage · Neu verfasst · Nicht generativ getestet.** Ersetzen Sie die Parameter in eckigen Klammern und fügen Sie die erforderlichen Materialien in das Tool ein, das die Bildbearbeitung unterstützt; Optionale und bedingte Eingaben werden gemäß der obigen Tabelle vorbereitet. Diese Vorlage wurde nicht zum Generieren der Beispiele auf dieser Seite verwendet.

```text
Create one promotional poster for [EVENT NAME] using [OPTIONAL APPROVED KEY VISUAL].
Use only these confirmed facts: [CORE MESSAGE], [DATE AND TIME], [LOCATION OR PARTICIPATION METHOD], and [CTA].
Preserve any supplied person, product, artwork, or brand mark without redesigning it.
Build a clear hierarchy for event name, message, logistics, and call to action.
Use [POSTER STYLE], [PALETTE], [IMAGE TREATMENT], and [FORMAT OR ASPECT RATIO].
Do not invent sponsors, speakers, endorsements, prices, availability, or event details.
Keep all exact wording readable and separate from decorative imagery.
Treat generated lettering as a visual draft requiring manual proofreading and final typesetting.
Verify bleed, resolution, color mode, accessibility, and output dimensions in a production tool when printing.
Deliver one poster preview image only.
```

## Überprüfen Sie die wichtigsten Punkte/Bewertung

Zeit, Ort, Teilnahmemethode und Veranstaltungsname werden nacheinander überprüft. Das generierte Diagramm kann die abschließende Layoutprüfung nicht ersetzen.

Lesen Sie jedes Veranstaltungsdetail Korrektur und erstellen Sie den präzisen Typ neu oder drucken Sie die Dateien separat aus.

Ergebnisrichtung: Veranstaltungsplakat. Wenn exakter Text, transparente Dateien, Vektoren oder eine Drucklieferung erforderlich sind, überprüfen Sie die tatsächliche Datei. Die verfügbaren Funktionen und Gebühren unterliegen der Beschreibung auf der Website.
