## Public prompt

**Modelo público recém-editado · Recém-criado · Não testado em geração.** Substitua os parâmetros de colchetes e anexe os materiais necessários na ferramenta que suporta edição de imagens; entradas opcionais e condicionais são preparadas conforme tabela acima. Este modelo não foi usado para gerar os exemplos nesta página.

```text
Create one composite family portrait using [LABELED PHOTO FOR EACH PERSON].
Include exactly [TOTAL PEOPLE] according to [RELATIONSHIPS AND LEFT-TO-RIGHT ARRANGEMENT].
Preserve every person’s identity, age cues, skin tone, face shape, hair, and distinctive features.
Do not omit, duplicate, merge, or substitute any person.
Normalize scale, camera angle, lighting, and color so the group feels visually coherent.
Use [SETTING] and [WARDROBE DIRECTION] while keeping clothing plausible for each subject.
Construct natural poses, hands, overlaps, eye lines, and floor contact.
Do not imply this was an actual shared photo session; it is a created composite.
Add no names or dates unless exact confirmed wording is supplied.
Deliver one complete family portrait image only.
```

## Confira os principais pontos/revisão

Devem ser fornecidas fotos de todos os membros, seu número, relacionamento e disposição. A imagem composta não pode ser considerada como um verdadeiro registro fotográfico de grupo.

Verifique a lista e divulgue que a imagem é uma composição, e não uma fotografia real de grupo.

Direção do resultado: Retrato de família completo. Quando for necessário texto exato, arquivos transparentes, vetores ou entrega impressa, verifique o arquivo real; os recursos e taxas disponíveis estão sujeitos à descrição do site.
