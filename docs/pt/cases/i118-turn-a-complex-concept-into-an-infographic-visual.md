## Manter e alterar/Editar resumo

- **Preservar / 保留：** Mantenha todos os fatos, números, ordem, hierarquia e relacionamentos exatamente como fornecidos.
- **Alterar / 改变：** Alterar iconografia, layout, código de cores, agrupamento visual e ênfase.

## Public prompt

**Modelo público recém-editado · Recém-criado · Não testado em geração.** Substitua os parâmetros de colchetes e anexe os materiais necessários na ferramenta que suporta edição de imagens; entradas opcionais e condicionais são preparadas conforme tabela acima. Este modelo não foi usado para gerar os exemplos nesta página.

```text
Create one infographic from [VERIFIED FACTS, STRUCTURE, AND RELATIONSHIPS] and [OPTIONAL STRUCTURE SKETCH].
Preserve every supplied fact, number, unit, sequence, category, and relationship exactly.
Use [FLOW / HIERARCHY / COMPARISON / TIMELINE] as the primary information structure.
Design a clear visual hierarchy with [PALETTE], consistent icons, labels, and generous spacing.
Connect elements only according to the supplied relationships; do not infer missing links.
Do not invent statistics, causes, conclusions, citations, or categories.
Keep text concise but do not paraphrase terms whose exact wording matters.
Treat generated lettering, charts, and symbols as a draft requiring factual and typographic review.
Rebuild precise charts, vectors, and accessible text in an appropriate production tool.
Deliver one infographic preview image only.
```

## Confira os principais pontos/revisão

Os relacionamentos, ordem e números são provenientes das informações fornecidas. A razoabilidade visual não significa que os fatos estejam corretos.

Validar as informações de forma independente; coerência visual não é prova factual.

Direção do resultado: Infográfico. Quando for necessário texto exato, arquivos transparentes, vetores ou entrega impressa, verifique o arquivo real; os recursos e taxas disponíveis estão sujeitos à descrição do site.
