## Manter e alterar/Editar resumo

- **Preservar / 保留：** Honrar os fatos escritos fornecidos, o texto exato e as restrições.
- **Alterar / 改变：** Projete [MOTIFS] com [LIMITED PALETTE] para [GARMENT COLOR] e [PRINT LOCATION]. Se solicitado, defina exatamente “[SLOGAN]” com forte legibilidade e contornos externos limpos.

## Public prompt

**Modelo público recém-compilado · Recém-criado · Não testado em geração.** Basta substituir os parâmetros de colchetes, sem necessidade de fazer upload de imagens de referência. Este modelo não foi usado para gerar os exemplos nesta página.

```text
Create one standalone T-shirt graphic about [THEME] from the following written brief only. No reference image or other attachment is needed.
Design [MOTIFS] with [LIMITED PALETTE] for [GARMENT COLOR] and [PRINT LOCATION]. If requested, set exactly “[SLOGAN]” with strong readability and clean outer contours.
Show the artwork without a garment mockup; verify resolution, ink limits and file transparency before production.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
