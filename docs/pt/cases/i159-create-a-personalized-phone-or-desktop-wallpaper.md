## Manter e alterar/Editar resumo

- **Preservar / 保留：** Honrar os fatos escritos fornecidos, o texto exato e as restrições.
- **Alterar / 改变：** Crie [SCENE OR ABSTRACT MOTIF] em [PALETTE AND STYLE]. Reserve [LOCK-SCREEN CLOCK AND ICON AREAS] como um espaço silencioso e mantenha detalhes importantes dentro de margens seguras para a colheita.

## Public prompt

**Modelo público recém-compilado · Recém-criado · Não testado em geração.** Basta substituir os parâmetros de colchetes, sem necessidade de fazer upload de imagens de referência. Este modelo não foi usado para gerar os exemplos nesta página.

```text
Create one wallpaper for [DEVICE AND ASPECT RATIO] from the following written brief only. No reference image or other attachment is needed.
Create [SCENE OR ABSTRACT MOTIF] in [PALETTE AND STYLE]. Reserve [LOCK-SCREEN CLOCK AND ICON AREAS] as quiet space and keep important details inside crop-safe margins.
Check the actual device crop and icon readability; no real person or supplied photo is required.
Use an original design. Do not imply fidelity to any existing person, product, property or artwork that has not been supplied.
Return one finished image only. Replace every bracketed field with your own details before generating.
```
