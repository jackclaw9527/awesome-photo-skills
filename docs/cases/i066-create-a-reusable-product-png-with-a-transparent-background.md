1. 按上表准备自己的素材，补齐该任务需要的准确文字或指定原稿。
2. 打开[对应需求页](https://dearsketch.com/intent/i066-create-a-reusable-product-png-with-a-transparent-background.html?utm_source=github&utm_medium=case&utm_campaign=dearsketch-public-cases&utm_content=i066_steps)，确认当前页面提供的输入方式与制作条件。
3. 选择本次要完成的一张图片或一个方案；多个方案分别制作。
4. 获取结果后，按下面的要点核对，再决定是否下载或进一步编辑。
