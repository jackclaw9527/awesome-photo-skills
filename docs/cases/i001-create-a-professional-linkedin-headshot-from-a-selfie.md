## 制作步骤

1. 按上表准备自己的素材，补齐该任务需要的准确文字或指定原稿。
2. 打开[对应需求页](https://dearsketch.com/intent/i001-create-a-professional-linkedin-headshot-from-a-selfie.html?utm_source=github&utm_medium=case&utm_campaign=dearsketch-public-cases&utm_content=i001_steps)，确认当前页面提供的输入方式与制作条件。
3. 选择本次要完成的一张图片或一个方案；多个方案分别制作。
4. 获取结果后，按下面的要点核对，再决定是否下载或进一步编辑。

## 检查重点

检查本人身份、五官和自然肤质，避免过度美化与虚构职业标识。

结果方向：专业半身头像。具体可用功能与费用以网站当时的说明为准。
