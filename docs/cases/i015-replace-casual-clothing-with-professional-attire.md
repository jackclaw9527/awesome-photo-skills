2. 打开[对应需求页](https://dearsketch.com/intent/i015-replace-casual-clothing-with-professional-attire.html?utm_source=github&utm_medium=case&utm_campaign=dearsketch-public-cases&utm_content=i015_steps)，确认当前页面提供的输入方式与制作条件。
3. 选择本次要完成的一张图片或一个方案；多个方案分别制作。
4. 获取结果后，按下面的要点核对，再决定是否下载或进一步编辑。

## 检查重点

只调整目标着装，检查领口、手部与身体边缘，避免改变本人外貌。

结果方向：正式着装照片。具体可用功能与费用以网站当时的说明为准。
