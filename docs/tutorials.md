# 5 个可以直接尝试的基础模板

这里提供 5 个为公开内容库单独编写的基础模板。上传自己的素材后，将相应文字交给支持参考图编辑的工具即可尝试。不同工具的输入方式、费用与可用能力不同，请以所用工具说明为准。

这些模板没有从网站的私有 Skill 导出，也没有用来生成本仓库现有的示例图。它们尚未经过逐模板模型实测，不保证复现示例图；示例图与教程模板分别标注。

## 1 宠物定制肖像

准备一张能看清眼睛、耳朵和主要花纹的宠物照片。以下示例选择暖白背景和简洁插画作为创作方向，可以自行替换。

```text
请以所附照片中的同一只宠物为主体，制作一张简洁的宠物肖像插画。
保留照片里可见的脸部结构、眼睛颜色、耳朵形状和主要花纹，
不要把它替换成另一只相似品种的宠物。
使用暖白背景、柔和色块和少量线条，让主体清楚、构图留有呼吸空间。
不添加姓名、日期、服饰、配件或水印。只输出一张最终肖像。
```

检查花纹是否对应、耳朵是否完整、是否仍能认出同一只宠物。

## 2 真人照片转卡通头像

准备一张清楚的人像。这个基础模板采用扁平色块，不要求复制任何特定作品或艺术家的表达。

```text
把所附照片中的人物转换成原创的卡通头像。
保留可识别的脸型、发型和照片里确实存在的配饰。
用清楚的轮廓、简洁色块和克制的阴影表达人物，背景保持单纯。
不要改变人物年龄观感，不加入照片中不存在的职业、身份或品牌元素。
头部和肩部构图，不加文字和水印，只输出一张头像。
```

检查人物是否可识别，再看头发边缘、眼镜和耳朵是否自然。

## 3 住宅水彩纪念画

准备一张能看清主要外立面的房屋照片。只画照片能确认的建筑信息。

```text
根据所附房屋照片制作一张水彩风格的住宅纪念画。
保留房屋的主要轮廓、屋顶、门窗位置和可见结构。
用轻薄的水彩色层和少量线条表达建筑，周围保留适量空白。
不增加照片看不到的新楼层、门牌、文字或虚构建筑装饰。
背景可以适度简化，但不要把原房屋改成另一栋建筑。只输出一张画。
```

先对照屋顶、窗户和入口位置，再检查水彩表现。

## 4 商品白底主图

准备一张清楚的商品照片；透明、反光和细小镂空结构需要特别检查。

```text
把所附照片中的同一件商品整理成干净的白底商品展示图。
保持商品本身的形状、比例、颜色、标签和可见细节，不更换商品型号。
移除与商品无关的背景杂物，让商品完整入画，边缘自然。
不要添加新的标签、卖点、品牌、配件或认证标记。
不添加装饰边框和文字，只输出一张最终商品图。
```

核对细小边缘和标签，再按实际销售渠道检查尺寸、留白与主图规范。

## 5 Logo 概念探索

将以下方括号内容换成自己的品牌资料。这里要求图形概念，不承诺矢量文件或商标可注册性。

```text
为一个[品牌领域]品牌探索一个原创图形标志概念。
品牌定位是[一句话定位]，主要面向[目标人群]。
用简洁形状表达[一个核心意象]，选择[主色]搭配中性色。
先只展示一个不含文字的图形标志，居中放在纯净背景上。
不要套用现有品牌标志，不加样机、装饰场景、口号或水印。
只输出一张概念图。
```

缩小查看是否仍然清楚，之后再做字标、矢量整理和使用场景验证。

## 从模板到自己的结果

先完成一次小范围尝试，检查主体与事实是否正确，再改变画风、构图或其他变量。遇到姓名、价格、尺寸、活动日期和准确文案，应逐字核对，不让模型代填。
