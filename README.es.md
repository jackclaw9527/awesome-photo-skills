## Preguntas antes de empezar

**¿Una plantilla reproducirá el ejemplo exactamente?**

No. Estas son nuevas plantillas públicas, no las instrucciones originales detrás de los ejemplos existentes. La salida depende de las imágenes de origen, la herramienta y la configuración. La Habilidad pública prepara una tarea y la incita; No incluye modelo, acceso API ni créditos de generación gratuita.

**¿Cada tarea comienza con una foto?**

No. Las composiciones familiares, las pruebas y los diseños de información pueden necesitar varias fotografías, un diseño original o una copia exacta. Algunos conceptos comienzan con el texto. Cada caso enumera sus insumos.

**¿Son estos archivos listos para producción o resultados de clientes?**

Las imágenes son demostraciones del proyecto. Verifique el texto, la transparencia, las dimensiones y cualquier requisito vectorial o de impresión en los archivos reales. Los términos de procedencia y redistribución de las imágenes se describen en la política de contenido.

[Política de imagen y contenido](./docs/es/content-policy.md) · [Contribuir con un caso](./CONTRIBUTING.es.md) · [Actualizaciones](./CHANGELOG.es.md)

Los permisos de redistribución de imágenes aún se están revisando. La visibilidad pública no otorga licencia de imagen ilimitada. Las características y precios del sitio web siguen el sitio web actual.
