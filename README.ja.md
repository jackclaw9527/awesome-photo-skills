## 最初のイメージを作成する

1. **エフェクトを選択します。** ケースを開いて、必要な入力を確認します。
2. **ツールを選択してください。** そのプロンプトを画像ツールにコピーするか、dearsketch で一致するタスクを開きます。
3. **独自の資料を使用してください。** テキストのみの概要の場合は、詳細を書き込んでください。写真タスクの場合は、必要な画像を添付してください。プロンプトを編集し、イメージを 1 つ生成します。
