## 始める前の質問

**テンプレートは例を正確に再現しますか?**

いいえ。これらは新しい公開テンプレートであり、既存の例の背後にある元の手順ではありません。出力はソース画像、ツール、設定によって異なります。公開スキルはタスクとプロンプトを準備します。モデル、API アクセス、無料生成クレジットは含まれません。

**すべてのタスクは 1 枚の写真から始まりますか?**

いいえ。家族の合成、試着、情報レイアウトには、数枚の写真、オリジナルのデザイン、または正確なコピーが必要な場合があります。一部の概念はテキストから始まります。それぞれのケースに入力をリストします。

**これらは本番環境に対応したファイルですか、それとも顧客の結果ですか?**

画像はプロジェクトのデモです。実際のファイルのテキスト、透明度、寸法、ベクターまたは印刷の要件を確認してください。画像の出所と再配布条件はコンテンツ ポリシーに記載されています。

[画像とコンテンツのポリシー](./docs/ja/content-policy.md) · [ケースを投稿する](./CONTRIBUTING.ja.md) · [アップデート](./CHANGELOG.ja.md)

画像の再配布許可はまだ審査中です。一般に公開しても、無制限の画像ライセンスは付与されません。ウェブサイトの機能と価格は現在のウェブサイトに準拠します。
